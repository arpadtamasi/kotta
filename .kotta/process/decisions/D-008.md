# D-008 — Build-first sorrend — T-024, aztán a crm-kit build a verdiktig; minden más utána

## Decision

A következő mérföldkő: **a crm-kit buildje lefut a pecsételt vizsga verdiktjéig.** A sorrend:

1. **T-024** (entitás nyitott kérdései) — az egyetlen szerszám-fejlesztés a build előtt, mert a crm-kit T-001 interjúja a valós próbája: az interjú már strukturált kérdésekkel fut.
2. **crm-kit: T-001 interjú** (ember, egy délután) → **T-009 vizsga** (pecséttel) → **P-001 build** → **T-010 verdikt**.
3. Utána, a build tanulságából: **T-025 reset** (az első módosítási körrel élesítve), majd **P-004 rename**, **T-019 sweep**, és a **nulladik futam** a oneandán.

## Context

Az operátor office-hours döntése (2026-08-01, második kör). Elfogadott premisszák: (1) a build ma indítható, szerszám-előfeltétel nincs — a P-018 is lefutott a mai szerszámmal; (2) a P-004 rename nem futhat a build alatt — a T-022 épp a crm-kit workspace-t migrálná építés közben; (3) a build maga tézis-teszt — a design doc 2. lépcsőjének greenfield változata élesben, a nulladik futam utána informáltabban tervezhető.

Az operátor a T-024-et az ajánlott „build azonnal" út elé sorolta, indoklással: az interjú legyen az új funkció első éles használata — a szerszám arra fejlődjön, amerre a használat húzza (F-024 elv).

## Consequences

- A T-024 a következő aktív munka; ready-kapuja az operátoré.
- A P-004 (rename) várakozik a verdiktig — a GitHub-átnevezés (D-006/1) kész, a többi nem sürgős.
- A T-019 sweep és a nulladik futam a build utáni kör; az F-025 (Progos mint kiadó) diszpozíciója változatlanul a futam eredményéhez kötött.
- T-026 (kis kontextus) a backlogban várja a build tapasztalatát — a brief tartalmát a build mutatja meg.
