# An intent becomes kept code through one gate

## Given

An operator who finds the board's hierarchy hard to read, and a coding agent in the chat.

## When

The agent orients, shapes a change telling the board's purpose first, the operator approves it at its gate, the agent builds it citing each promise, and the operator runs the gap report.

## Then

Before any code was written the operator saw what would change and said yes once; while it was built the gap report showed which promises were kept and which were left; nothing turned out only afterwards.
