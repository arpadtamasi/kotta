# The human sees in time what the machine does

## Outcome

The human who directs coding agents sees what the agents will build before they build it, and sees whether the code keeps it while it is built — not after.

## Context

People who work with coding agents say the trouble is that it is not transparent what the machine does, and that it turns out late. Kotta keeps the agreement in the repository, puts one human yes before the code, and measures the code against the agreement.

## Baseline and target

Baseline: not measured. Target: every example listed under measured_by holds.
