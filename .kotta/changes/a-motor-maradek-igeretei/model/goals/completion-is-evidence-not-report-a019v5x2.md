## Outcome

Nothing counts as kept because an agent said so. A promise counts as kept when the code, a test or a command definition that keeps it names it, and the gap report reads that from the repository.

## Context

Agents plausibly narrate work they did not do. The record must be stronger than the narration.

## Baseline and target

Baseline: "the agent reported success". Target: every accepted promise is either named where it is kept or admitted as not kept yet, and a promise that is neither is refused, whatever was reported.
