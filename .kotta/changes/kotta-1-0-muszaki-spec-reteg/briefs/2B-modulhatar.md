Worktree: `../kotta-k1-modules`, ág `spike/k1-modules` (az 1. szakasz fejéről). Csak ott dolgozz; commitolj; ne pusholj. A `src/cli/index.ts`-ben csak a saját parancsodat regisztráld.

Olvasd előbb: a change `proposal.md`, `specs/module-boundary`, `specs/evidence`, `design.md` 3., 6., 7. döntés, `tasks.md` 1.2, 2, 5.1; `src/commands/gap.ts` (a mai bizonyíték-jelentés: node-id szövegkeresése commitolt fájlokban — ez marad a „cited” szint), `src/spec/registry.ts`, `src/filesystem/workspace.ts`, `src/git/git.ts`, a `tests/` mintái; és `briefs/README.md` közös szerződéseit.

## Feladat

1. **Modul-felfedezés manifestekből** (`src/core/modules.ts`): modul az a könyvtár, amit manifest annak nyilvánít — pnpm/npm workspace (`pnpm-workspace.yaml` `packages:`, `package.json` `workspaces`), Python (`pyproject.toml` `[tool.uv.workspace]` members, vagy alkönyvtári `pyproject.toml` `[project]`-tel), Dart (`pubspec.yaml`), Rust (`Cargo.toml` `[workspace] members`), Go (`go.mod`). Manifest nélküli repó egy modul (a gyökér). Modulonként: `name` (a csomagnév — a kulcs, pl. `@goschool/assistant-core-chat-ui`), `path`, `kind`, deklarált függések más modulokra, beleértve a repón kívülieket `file:` úton vagy verziótartománnyal (`external: true`, a feloldott spec-kel, ld. 4.). Modulon kívüli kód a `(root)` álmodulé. Parancs: **`kotta modules [--json]`**.
2. **A node modulja a bizonyítékából derül ki:** minden elfogadott node-hoz azoknak a moduloknak a halmaza, amelyek fájljai hivatkoznak az id-jére (kód/teszt/parancs, a `gap` mai osztályozása szerint). Egy modul → az a node modulja. Több → **kilógó node**. Nulla → besorolatlan. `module:` frontmattert soha nem olvasunk — kivéve az **interfész**-node-on, ahol azt jelenti: „ez a modul felülete”.
3. **Határ-ellenőrzések** (`specs/module-boundary`), **`kotta modules check [--json]`**, és a `kotta validate`-be figyelmeztetésként (nem hibaként): (a) minden modulnak, amelynek van deklarált nyilvános felülete (`exports`/`main`/`types`, Python `__init__`, Dart `lib/`), legyen legalább egy interfész-node-ja `module:`-lal → „hiányzó interfész”; (b) két modulban bizonyított node → „kilógó node”, a modulok megnevezésével és a javaslattal, hogy interfészbe kerüljön; (c) A modul nem-interfész node-ja, amely B modul nem-interfész node-jára hivatkozik → „modulhatáron átnyúló hivatkozás”, az interfész a megengedett cél; (d) nem létező modulra mutató `module:` → hiba.
4. **Repók közötti hivatkozás** („a közös mag ígéretére hivatkozunk, nem másoljuk”): interfész-node `reference:` blokkja `{ module: <csomagnév>, version: <semver vagy commit>, resolve: file | package | git }` — a felület egy másik repó moduljáé. Feloldás sorrendben: (a) a függés `file:` útja a manifestből → annak a repónak a `.kotta/spec/interfaces/` egyező node-ja; (b) a telepített csomagban szállított spec (`node_modules/<name>/kotta-spec/` — definiáld, és írd meg a **`kotta modules publish-spec`**-et, amely egy modul interfész-node-jait és a hozzájuk kötött szabályokat/példákat `<modul>/kotta-spec/` alá másolja, hogy a csomag a típusdefiníciókhoz hasonlóan az ígéreteit is szállítsa); (c) git url + commit. `kotta modules check` jelenti: a rögzített verzió nem egyezik a feloldott spec aktuális commitjával/verziójával → „a mag megváltozott a rögzített verzió óta”; egy interfész-node szövege >80%-ban azonos egy feloldható idegen interfésszel → „elcsúszott másolat, hivatkozásra váltandó”.
5. **Bizonyíték-szintek a `gap`-ben** (`specs/evidence`), csak olvasó: node-onként `level: none | cited | bound` — `cited` = az id egy commitolt fájlban szerepel (mai viselkedés), `bound` = az id egy **teszt nevében** szerepel (`it(`/`test(`/`describe(` string, `#[test] fn` név, Python `def test_` név, Dart `test('…')`). A JSON-ba `module` és `straddler`, plusz modulonkénti összesítés (ígéret, cited, bound, none). A tesztfuttató `prove` parancs nem scope; tervezési jegyzet a DECISIONS-be.
6. **Tesztek:** fixture pnpm-workspace 2–3 csomaggal és egy csomagon kívüli `functions/`-szel; egy, két és nulla modulból hivatkozott node-ok; interfész `module:`-lal; repók közötti `file:` függés egy testvér-fixture repóra saját `.kotta/spec`-kel; közel-másolat interfész; elavult `reference.version`. `npm run typecheck`, `npm test`, `npm run build` zöld.

Minden tisztázatlan pont a change `DECISIONS.md`-jébe. Zárójelentés magyarul, tömören: parancsok/opciók, a felfedezés és levezetés szabályai, a négy ellenőrzés és a jelentésük, a repók közötti elrendezés, a `gap` új mezői, tesztszámok, typecheck/build, commitok, DECISIONS-bejegyzések.
