# D-006 — A rename indul — GitHub most, workspace-ek symlinkkel, npm a következő release-szel

## Decision

A D-005 munkanévből végrehajtás lesz, szakaszolva:

1. **GitHub: most.** `arpadtamasi/a-team` → `arpadtamasi/kotta`. A GitHub a régi URL-eket automatikusan átirányítja, a lépés alacsony kockázatú és visszafordítható.
2. **npm: a következő release-szel.** Az új csomagnév a szabad, pontozatlan `kotta` (ellenőrizve: 2026-08-01-én E404). A `@arpadtamasi/a-team` deprecated-jelölést kap, ami az új névre mutat.
3. **CLI: `kotta` bináris, `a-team` alias marad** egy átmeneti időre — a szomszéd projektek szkriptjei nem törhetnek el egyik napról a másikra.
4. **Workspace-könyvtár: a `.a-team/` marad az elsődleges beolvasott út**, a CLI megtanulja a `.kotta/`-t is; a szomszéd projektekben (oneanda, flowbench, crm-kit) **symlink** hidalja át az átmenetet, nem tömeges átnevezés.

## Context

A crm-kit vevő-README elkészült, és a terméktörténet („kotta, amiből összerakod") nem mesélhető el úgy, hogy az eszköz repója közben A-Team néven fut. Az operátor döntése: a GitHub-átnevezés mehet most; a szomszéd projekteknél inkább symlink; a teljes szótárcsere (D-004: signal/ticket/task/goal) továbbra is későbbi, egyben kezelendő kör.

## Consequences

- A végrehajtás T-020 szerződése szerint fut; a GitHub-átnevezés ma megtörténik, a többi a ticket ütemében.
- A D-005 „working name" státusza ezzel megszűnik: a név éles.
- Minden új dokumentum és termékfelület a Kotta nevet használja; az A-Team név csak történeti hivatkozásban marad.
