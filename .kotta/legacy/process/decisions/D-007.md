# D-007 — A rename teljes — a workspace-könyvtár is .kotta lesz, a szomszéd projektek migrálnak

## Decision

A D-006/4 pont felülírva: a `.a-team/` könyvtár **nem marad** elsődleges út. A teljes rename része a workspace-könyvtár is:

1. Az új elsődleges könyvtárnév **`.kotta/`** — az init ezt hozza létre, a CLI és a UI ezt keresi először.
2. A `.a-team/` beolvasása kompatibilitásként megmarad egy átmeneti időre.
3. **A szomszéd használó projektek migrálnak** — nem symlink-híd, hanem tényleges átnevezés (`git mv .a-team .kotta`), visszafelé mutató symlinkkel a régi szkriptek kedvéért. Érintett workspace-ek (2026-08-01-i felmérés): a kotta repo maga, oneanda, crm-kit, flowbench.
4. A teljes átnevezést egy dedikált package fogja össze, hogy a lépések sorrendje és a stop-on-failure érvényesüljön.

## Context

Az operátor döntése a D-006 után közvetlenül: „a könyvtár .a-team benne; kell egy package a teljes átnevezésre; a használó projektekre is itt a szomszédban." A crm-kit vevő-README után a fél-rename tarthatatlan: a termék Kotta néven fut, miközben a vevő által is látható könyvtár A-Teamet mondana.

## Consequences

- A D-006 1–3. pontja (GitHub kész, npm, CLI-alias) változatlan; a 4. pont helyére ez a döntés lép.
- A végrehajtás a rename-package szerint fut: T-020 (névfelületek) → T-021 (könyvtár-elsődlegesség + saját repo migrál) → T-022 (szomszéd projektek migrálnak).
- A migráció minden érintett repóban commit — a történet ott is látszik, nem csak nálunk.
