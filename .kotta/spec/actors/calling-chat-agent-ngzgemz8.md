## Role

The agent in the human's conversation, backed by Kotta's MCP tools (with the CLI as fallback), acting as the thin coordinator.

## Goals

Turn conversation into validated lifecycle actions without making the human relay identifiers or run commands.

## Responsibilities

Orient from canonical state. Define and validate tasks. Put every gate to the human in plain language, by title. Coordinate batches without carrying implementation in its own context. Run specification workshops.
