## Story

As a developer or technical lead evaluating Kotta, I want the first viewport to tell me what Kotta makes possible and show the mechanism behind that promise, so I can decide whether to install it or inspect the repository without decoding a process manual first.

## Value

The public page earns attention with one sharp product claim, then converts that attention into an informed action. Kotta reads as an executable agreement for human-AI work, not as another generic agent, tracker, or prompt template.

## Notes

The page is English and keeps Kotta's own product truth. Its marketing hierarchy may take inspiration from Graft's directness: very large type, a short supporting argument, an immediate install or GitHub action, and a concrete demonstration before long explanation. It does not copy Graft's brand, fabricate benchmarks, imply customers, or add hosted-service claims.
