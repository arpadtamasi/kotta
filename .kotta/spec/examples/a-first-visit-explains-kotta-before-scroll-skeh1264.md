## Given

A first-time visitor opens the public Kotta page on a supported desktop or mobile viewport with no prior knowledge of the product.

## When

The first viewport finishes rendering.

## Then

The visitor can read one unmistakable offer, reach a primary install or GitHub action without scrolling, and see a concrete repository-native path from stated intent through agent execution to evidence-backed human acceptance. The page makes no unsupported commercial or benchmark claim, remains useful without JavaScript, has no horizontal overflow, and preserves semantic structure, keyboard access, visible focus, and reduced-motion behavior.
