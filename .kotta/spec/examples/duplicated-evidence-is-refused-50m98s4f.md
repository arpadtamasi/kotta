## Given

A task submitted for review with the same thousand-word narrative pasted into both the visual-evidence check and the accessibility check.

## When

Validation compares the evidence entries.

## Then

The submission is refused, naming the two checks holding identical text and the rule violated; each check must be answered by evidence that addresses it.
