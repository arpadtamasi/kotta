## Given

Raw intent - "exports should be filterable" - captured as a backlog contract.

## When

The agent drafts the definition and validates it while a required section is still missing.

## Then

Validation refuses, naming the missing section or profile requirement; the contract stays backlog until the definition is complete and Open decisions truthfully say none remain. Only then is the human asked to sign.
