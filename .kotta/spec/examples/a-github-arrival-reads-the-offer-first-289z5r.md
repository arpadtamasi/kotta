## Given

A developer who has never used Kotta opens `github.com/arpadtamasi/kotta` from a link, with no prior knowledge of the product and no intention yet to install anything.

## When

They read the rendered repository page from the top, without scrolling past the first two screens.

## Then

They can state what Kotta is for, recognise whether they are the intended reader, and name at least one thing Kotta deliberately does not do — before the page asks them to install anything. The install command they eventually reach names the version the repository actually publishes, and the skills-install instruction matches the one the public page gives. Compatibility and migration reference material is present on the page but does not precede the product claim.
