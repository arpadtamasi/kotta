## Source

A new user with Node.js 20+, Git, and a supported agent host already installed.

## Stimulus

Following the documented path from package install through workspace init to the first defined contract.

## Environment

A fresh machine and repository, guided by the shipped skills.

## Artifact

The CLI, kotta sync skill installation, and the onboarding documentation.

## Response

The guided path completes without dead ends; every failure names its corrective action.

## Measure

At most five minutes end to end; the release canary measures and records the result per release.
