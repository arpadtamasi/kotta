## Rule

Discovered information never becomes scheduled work by itself. The path is capture with evidence, validation, and a human-approved disposition. The constructive exits are amend-spec - the noticing changes the agreement, and tasks follow from the landed delta - and create-task, which only feeds the define gate. The two are named apart, because they name different things: an observation's title says what was noticed, a task's says what will be done. So a create-task disposition carries a title for the work; where none is given the capture keeps the observation's wording and the result says so, naming what would replace it. A symptom standing in as the name of the work is a state to leave, not one to live under - it reaches every list, every gate question and every summary a human reads.

## Rationale

Silent scope expansion is how delegated work escapes control. Keeping intake decoupled from execution keeps the queue honest and the active work bounded - and giving the noticing a door into the spec keeps the workspace from producing tasks about tasks.

## Scope

Every intake channel: agent discoveries mid-task, human notes, external bug reports, connector feedback.
