title: "An observation is not a task"
---

## Rule

Discovered information never becomes scheduled work by itself. The path is capture with evidence, validation, and a human-approved disposition. The constructive exits are amend-spec - the noticing changes the agreement, and tasks follow from the landed delta - and create-task, which only feeds the define gate.

## Rationale

Silent scope expansion is how delegated work escapes control. Keeping intake decoupled from execution keeps the queue honest and the active work bounded - and giving the noticing a door into the spec keeps the workspace from producing tasks about tasks.

## Scope

Every intake channel: agent discoveries mid-task, human notes, external bug reports, connector feedback.
