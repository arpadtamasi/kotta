## Definition

The relation between a task and the accepted specification: every acceptance condition of the task is derivable from the accepted spec nodes the task references.

## Usage

Checked at define; a covered task needs no sign gate and crosses one human gate, at close. Coverage is named, not inferred: the task lists the nodes it executes.

## Non-examples

A prose claim of relatedness with no referenced node. A reference to a spec node not yet landed on the base branch. Test coverage.
